# UI kit

Contents of `packages/ui`; the rules are in packages/CLAUDE.md and the root CLAUDE.md. Keep this list current when you add or change a file here.

- shared UI kit: number formatting, theme (`theme.css`: the base layout, including split view, and on `:root` the clean look's shared values `--look-*`, UX2: corners, shadows, the card colour, the bright blue glow and fill, target sizes, spacing; checked by `test/look.test.ts`; each feature's own styles are `src/styles/<feature>.css`, every selector starting with `.<feature>`, loaded by the app without a list), the workspace button (`switcher.ts`, U0f2b: DESIGN ▾ naming the page on screen, its menu the ten workspaces, the one on screen marked, the ones not built yet greyed with Coming soon; `styles/workspace-menu.css`; `test/switcher.test.ts`), split choices (`split.ts`), the warm-workspace pool (`warm.ts`, X7: one mounted instance per workspace, living in one pane, asleep unless shown), the link badge, the downstream chip (`downstream-chip.ts`), the file-drop outline (`styles/file-drop.css`, X6a) and the change note (`change-note.ts`; the strip of notes the shell shows over each pane is styled in `styles/notes-strip.css`), the Settings page (`settings.ts`: six card sections, the browser-only `SettingsStore`; `styles/settings.css`, `styles/settings-button.css` for the top bar gear; browser check `apps/fission/e2e/settings.mjs`), the keyboard shortcuts list (`shortcut-list.ts`, `styles/shortcut-list.css`, X7b), the top bar's Undo and Redo (`styles/undo-redo.css`, step 20b), the AI assistant panel's styles (`styles/assistant.css`, AI2), the guide's styles (`styles/guide.css`; the guide itself is in packages/viewport `src/guide/`), placeholder page.
- `styles/split-view.css`: split view's one-row toolbars, the pane's choice in the toolbar row, the placeholder card; `defaultSplit` picks the first working workspace.
- `styles/dark-select.css`: every drop-down list's open list dark and readable (`class="dark-select"` on each select: `color-scheme: dark` and solid dark options, since Windows Chrome painted the list white under light words); browser check `apps/fission/e2e/select-lists.mjs`.
- `save-file.ts`: saving as a desktop app does (`saveFile`: the browser's save picker where there is one, else `askName`'s small box and a download; a returned handle is written again without asking; `fileNameFor` makes names safe; `PROJECT_KIND` .spindle, `STL_KIND`); a page driven by a test downloads under the suggested name; `test/save-file.test.ts`, `e2e/save-name.mjs`, `styles/save-name.css`.
- `command-search.ts`: the S key's command search box (`commandSearch`: every command the workspace gives, by name with its key, typing narrows, arrows and Enter run one, Escape or a press outside closes; an off command stays listed, dimmed, with its reason, and never runs; `matchCommands` is the pure matcher); `test/command-search.test.ts`, `e2e/shortcuts.mjs`, `styles/command-search.css`.
- `file-menu.ts` (U0f2a): the app bar's File ▾ (`fileMenu`, `fileSections`): New, Open…, Save, Save As…, then the exports; Open, Save and Save As the shell's, New and the exports the workspace's on screen (core's `FileEntries`), read each time it opens, off with why where there is nothing to do; `test/file-menu.test.ts`. `styles/app-bar.css`: the bar's ends (File ▾, the Save, Undo and Redo icons; AI, Guide and Community small at the right; Save in File ▾ and File ▾ filling the row at phone width).
- `open-elsewhere.ts`: the shell's question before a file opened, dropped or pasted takes you to a workspace not on screen ("Open in Image?", `openElsewhere`, `openElsewhereWords`; Cancel, Escape or a click outside open nothing); `test/open-elsewhere.test.ts`, browser checks in apps/fission `e2e/files.mjs`. `styles/open-elsewhere.css`.
- `menu-button.ts` (U0d): a button that drops down a menu of sections and items (keys, off items saying why, ArrowUp/Down, Home/End, Escape back to the button, a press outside closes; placed under the button by `menuPlace`, kept on the screen). Design's Insert ▾, the toolbar's groups (U0f1), the app bar's File ▾ and DESIGN ▾ (U0f2: an item's `note` at its right, `current`, the button's `setLabel`). Styles `styles/menu-button.css`; tested in `test/menu-button.test.ts`.
- `styles/save-mark.css`: the save status as a small mark at the corner of the app name at phone width (the words stay in `#save-status` for screen readers).
- `icons.ts` (U0f, from U3a): the app's own flat two-tone icons on a 24 grid (lines in `currentColor`, the second tone the same colour at 0.35), `iconSvg(doc, name, size)` for the toolbars, menus and browser rows. `test/icons.test.ts` reads every path back (absolute M L H V A C S Z only) and checks it stays 2 in from the edge; the sheet at 16, 20, 24 and 48 px in both themes is `/mnt/project-files/compact-ui/u0f/icon-sheet.png`. `withIcon(el, name, size)` puts an icon before an element's words, kept in a `.tool-word` span (its accessible name).
- `tool-group.ts` (U0f1): one group of the Fusion-style toolbar, `toolGroup(doc, { name, menu?, solo? })`: a row of icon buttons (`add`, 24 px, `TOOL_ICON_SIZE`; words hidden from sight, kept as the name) over the group's name, which is its menu's button ("CREATE ▾") when it has one; a solo group (Insert ▾) is one button, its icon over its name. At phone width each group is one row, its name first. `menu-button.ts` items and button take an `icon`. Styles `styles/toolbar-group.css`; tested in `test/tool-group.test.ts` and `apps/fission/e2e/toolbar.mjs`.
- `styles/phone-short.css` (U5a): a phone held sideways (500 px tall or less: the toolbar one 45 px row) and a window 641–760 px wide (AI, Guide and Community icons only); class `phone-short` on `<body>`, every rule inside a media query; tested in `apps/fission/e2e/phone-short.mjs`.
- `styles/phone-sheet.css` (U5b): at 640 px and under the page never scrolls: the view fills the height, Browser, Properties, the assistant and every menu list are bottom sheets (class `phone-sheet` on `<body>`); tested in `apps/fission/e2e/phone-sheet.mjs`.
- `skeleton.ts` (loading skeletons, 10-29): shimmering placeholder shapes while something loads (`skeleton(doc, "app" | "view" | "lines")`, `holdSkeleton(host, shape)` until `done()`, `adoptSkeleton` for one already in the page, `whileLoading`); invisible for the first `SKELETON_DELAY_MS` (200), faded out over `SKELETON_FADE_MS` (160) once seen (`leaveAfter`), still under reduced motion. Styles `styles/skeleton.css`; tested in `test/skeleton.test.ts` and apps/fission `e2e/skeleton.mjs`.
