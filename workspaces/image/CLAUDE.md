# Image workspace

Contents of `workspaces/image`; the rules are in packages/CLAUDE.md and the root CLAUDE.md, progress in `docs/progress/image.md`. Keep this list current when you add or change a file here.

- the Image workspace, its base (G1, done): `physical-size.ts` file headers, `limits.ts`, `document.ts`, `adjust.ts` (G1a; Pillow oracle fixtures in `test/fixtures/`, a seeded fuzz in `test/fuzz.test.ts`); `open.ts`, `panels.ts` and the page `workspace.ts` (G1b; Brightness slider and layer Hide, G1c; phone width and focus checked, G1d), which shows the image through the viewport's `showImage`, and with nothing open its own empty 2D view (`showImage(null)`; never `clearImage` while mounted, which gives back Design's body). Brightness has a slider and an exact-percent box kept in sync.
- `src/styles/image.css`: the panels' styles (properties in a `.image` box, the layer list `.image.tree`).
- `representations.ts` (G2a): each layer handed to other workspaces as an Image through the registry (`image.layer` producer, live `imageObjects` handles, `checkImageRep`), and the PNG/JPEG importer.
- `orientation.ts` (files hunt, 2026-11-01): a photo's EXIF orientation (JPEG APP1 before the scan, PNG eXIf before IDAT with a good checksum, where the browser reads it): `readOrientation` gives it and the file with every orientation set to 1 for the decoder, so the browser never turns it; `orientPixels` turns the stored pixels upright (5–8 swap width and height); open.ts checks the decoded size against the stored one first. Tests: `test/orientation.test.ts` (each orientation worked by hand on a 3 × 2 image, a seeded fuzz), browser check `apps/fission/e2e/files-hunt.mjs`.
