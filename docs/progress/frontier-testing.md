# Frontier testing

The testing workstream's progress file: harnesses that keep the boolean and curved-surface testing at the level of the best kernels and testing cultures, built while usage is plentiful so they keep catching bugs cheaply later. Ben's asks (2026-10-26): build T1–T6 before Combine (35f), then T7, a cold review proving all six work; put the rest in the roadmap at their places; run these threads one at a time, never two at once.

Where each idea comes from (checked against the sources on 2026-10-26): swarm testing, Groce et al., ISSTA 2012 (42% more distinct compiler crashes than the all-on default); "sometimes" assertions, Antithesis; BUGGIFY, FoundationDB; near-miss inputs, Kettner et al., "Classroom examples of robustness problems in geometric computations"; affine-equivalent inputs, Spatter (34 bugs in spatial databases, most in the geometry library); test-case reduction, C-Reduce (PLDI 2012); Manifold's FuzzTest of random union/difference chains; Trettner et al. 2021's milling endurance test (Cork failed after 17 cuts); fault injection, SQLite's anomaly tests; known-failure marks that report a surprise fix, OpenCascade's DRAW `TODO` (BAD, IMPROVEMENT).

- [x] T6. Fault injection: FISSION_FAIL_AT=<n> (kernel debug builds) makes the nth sub-step (an intersection, a face split, a classification) report failure. The operation must return a clean `KernelError`, leave its inputs untouched (bit for bit), and the next call must work; in the app, a rebuild with a failing feature keeps the document valid and undoable. Run for every n until the operation completes, like SQLite's out-of-memory loop.
  - [x] T6a. Kernel side: in debug builds only (the app's release build has none), the nth checked sub-step of an operation can be made to fail once; each operation is run failing at check 1, 2, … until it completes, and must give back the injected error, leave its inputs unchanged and answer the next clean call exactly as it does alone. Covered: extrudes (a square: 3 checks by hand; arcs with a circle and a square hole; a circle 1,000 km out), the same in a turned flipped frame, the body store building a box, cylinder, sphere and an extrude beside a held body, and the boolean checks of four pairs either way round. Planted wrong handling (swallowing, changing the error, changing the input, leaving itself broken) each caught; three deliberate kernel breaks each caught. Next, T6b (kernel details in the kernel repo).
  - [x] T6b.
